# Super Store Sales Data Analysis – Week 2

## Project Overview

This project is **Week 2 of the Super Store Sales Data Analysis** series.

The project focuses on performing **Exploratory Data Analysis (EDA)** on the Super Store sales dataset using Python. It includes data preprocessing, date analysis, delivery time calculation, category-wise sales and profit analysis, distribution analysis, discount-profit analysis, and correlation analysis.

The project uses **Pandas, NumPy, Matplotlib, and Seaborn** for data manipulation, analysis, and visualization.

---

## Objectives

The main objectives of this project are:

* Load and explore the Super Store sales dataset.
* Convert order and shipping dates into proper datetime format.
* Calculate the number of delivery days for each order.
* Identify unique product categories.
* Check for missing values.
* Analyze sales by category.
* Compare profit across different categories.
* Understand sales and profit distributions.
* Analyze the relationship between discount and profit.
* Identify relationships between numerical variables using correlation.

# Project Workflow

## 1. Import Required Libraries

The project starts by importing the required Python libraries.

```python
import pandas as pd

import seaborn as sns
```

## 2. Load the Dataset

The Super Store CSV file is loaded using Pandas.

```python
df = pd.read_csv("samplesuperstore - samplesuperstore.csv")
```

---

## 3. Initial Data Exploration

The dataset is explored using:

```python
df.head()
```

This displays the first few records of the dataset.

The structure and data types are checked using:

```python
df.info()
```

```python
df.describe()
```

---

# 4. Date Conversion

The `Order Date` and `Ship Date` columns are converted into datetime format.

```python
df['Order Date'] = pd.to_datetime(df['Order Date'])

df['Ship Date'] = pd.to_datetime(df['Ship Date'])
```

This makes it easier to perform date-based calculations and analysis.

---

# 5. Delivery Days Calculation

A new column called **Delivery Days** is created to calculate the number of days taken to ship an order.

```python
df['Delivery Days'] = (
    df['Ship Date'] - df['Order Date']
).dt.days
```

### Formula

```text
Delivery Days = Ship Date - Order Date
```

This helps in understanding the delivery duration of orders.

---

# 6. Category Analysis

The unique product categories are identified using:

```python
df['Category'].unique()
```

The dataset contains three main categories:

* Office Supplies
* Furniture
* Technology

---

# 7. Missing Value Analysis

Missing values are checked using:

```python
df.isnull().sum()
```

This helps identify columns that contain missing data.

---

# 8. Sales by Category

Category-wise total sales are calculated using `groupby()`.

```python
category_sales = df.groupby('Category')['Sales'].sum()
```

A bar chart is then created to visualize total sales for each category.

```python
category_sales.plot(
    kind='bar',
    figsize=(8,5)
)

plt.title("Sales by Category")
plt.ylabel("Total Sales")
plt.show()
```

### Purpose

This visualization helps compare the total sales generated by different product categories.

---

# 9. Sales Distribution

# 13. Discount vs Profit Analysis

The project analyzes the relationship between **Discount** and **Profit**.

The available discount values are checked using:

```python
df["Discount"].unique()
```

A scatter plot is created:


# 14. Correlation Analysis

Correlation is used to understand relationships between numerical variables.

First, numerical columns are selected:

```python
numeric_df = df.select_dtypes(
    include="number"
)
```

The correlation matrix is calculated:

```python
corr = numeric_df.corr()
```

A correlation heatmap is then created:

```python
sns.heatmap(
    corr,
    annot=True
)

plt.title("Correlation Heatmap")
plt.show()
```

### Purpose

The correlation heatmap provides a visual representation of relationships between numerical variables in the dataset.
